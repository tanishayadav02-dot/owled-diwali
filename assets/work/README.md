Put work thumbnails here (WebP, about 1080×1350), named after their id in `data/work.js`, e.g. `w01.webp`.
Then set `thumb: 'assets/work/w01.webp'` on that piece. Pieces with `thumb: ''` get a generated cover in their stall's colour.

Also add `assets/og.jpg` (1200×630): the preview image WhatsApp and LinkedIn show when you send the link.
